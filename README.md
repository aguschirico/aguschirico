### Hi, I'm Augusto

Software engineer in Barcelona. Mostly backend, cloud and distributed systems, with a few years deep in Bitcoin and Lightning. These days I build AI-native products and spend a lot of time figuring out how to work well with coding agents without losing the engineering underneath.

I write down what I find at [augustochirico.dev](https://augustochirico.dev).

#### Things I've built

- **[docmux](https://github.com/aguschirico/docmux)**: a document converter in Rust. Markdown, LaTeX, Typst, DOCX and HTML through one AST, MIT-licensed and small enough to run in the browser via WASM.
- **[license-audit-skill](https://github.com/aguschirico/license-audit-skill)**: a Claude Code skill that checks npm licenses, WASM binaries and postinstall scripts before they reach production. No dependencies beyond pnpm, jq, find and grep.
- **[net-lnauth-identity](https://github.com/aguschirico/net-lnauth-identity)**: passwordless login with LNURL-auth on top of ASP.NET Identity and SignalR.
- **[liquid-scan](https://github.com/aguschirico/liquid-scan)**: a TypeScript library for scanning Liquid Network wallets and UTXOs.
